Sobre o Feira Limpa

FL

Feira Limpa

Uma plataforma demonstrativa para aproximar a comunidade das feiras livres e incentivar o cuidado com os espaços públicos.

O que você pode fazer?

  • Consultar feiras livres cadastradas no protótipo.
  • Pesquisar por nome e cidade.
  • Salvar feiras favoritas.
  • Registrar e acompanhar denúncias de limpeza.
  • Consultar suas contribuições no perfil.

Sobre os dados

Esta versão foi preparada para hospedagem estática no GitHub Pages. Os dados ficam no armazenamento local do navegador e não são compartilhados com outros dispositivos ou usuários. As informações de feiras são demonstrativas e precisam ser verificadas.
